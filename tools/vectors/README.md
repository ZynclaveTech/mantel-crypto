# Mantel Protocol v2 — reference implementation and test vectors

`vectors.json` is the **oracle** for Protocol v2. The iOS and Android crypto
cores are written against it and must reproduce it byte for byte.

## Why this exists

The v1 vectors were generated by the iOS test suite and committed. That made
iOS the oracle: an iOS bug would be encoded into the vectors, and Android
would faithfully conform to the bug. It also meant running the iOS suite
mutated a tracked file.

This package is an independent third implementation. Clients only ever *read*
`vectors.json`.

## Rules

- **Never edit `vectors.json` by hand.** Regenerate it: `npm run generate`.
- **Nothing in `src/` may call a random-number generator.** Every input is a
  constant in `src/constants.mjs`. That is what makes regeneration
  reproducible, and therefore what makes a diff meaningful.
- **A diff in `vectors.json` is a wire-format change.** Treat it as one: it
  breaks every already-encrypted photo. CI fails on undeclared drift.

## Layout

| Path | Responsibility |
|---|---|
| `src/constants.mjs` | Every fixed input |
| `src/kdf.mjs` | Argon2id, loginKey, variant subkeys |
| `src/keybox.mjs` | `crypto_secretbox` symmetric wrap |
| `src/identitybox.mjs` | `crypto_box` authenticated sharing |
| `src/stream.mjs` | STREAM chunked AEAD |
| `src/safetynumber.mjs` | 60-digit fingerprint |
| `generate.mjs` | The only file that does I/O |

## Commands

```bash
npm install
npm test          # round-trip and negative tests
npm run generate  # rewrite vectors.json
```
